# PRIN135 Demo 03: CSS

A set of short, focused activities. Each numbered folder covers **one concept** with a live demo and a fill-in-the-TODOs exercise.

| # | Folder | Concept | You'll practise |
|---|---|---|---|

| 01 | [`01-selectors`](01-selectors/) | Selectors | Element, class, ID, attribute, combinators, pseudo-classes, pseudo-elements |
| 02 | [`02-specificity-cascade-inheritance`](02-specificity-cascade-inheritance/) | Specificity, cascade & inheritance | Which rule wins, `!important`, `inherit`, a specificity calculator, debugging puzzles |

| 07 | [`07-border`](07-border/) | Border | Styles, single sides, `border-radius`, hover jumps, `outline` |

| 13 | [`13-floats`](13-floats/) | Floats | Text wrap, collapsing parents, clearfix, `clear` |

Open [`index.html`](index.html) in a browser for links to every demo.

## How each activity works

```
00-folder/
  README.md          ← key ideas, steps, and reflection questions
  starter/
    index.html       ← finished HTML (don't edit)
    style.css        ← complete the numbered TODOs here
  solution/
    index.html
    style.css        ← answer key
```

1. Read the folder's `README.md`.
2. Open `starter/index.html` in your browser, and `starter/style.css` in your editor.
3. Complete the TODOs in order. Save and refresh after each one.
4. Compare with `solution/`, then answer the reflection questions.
