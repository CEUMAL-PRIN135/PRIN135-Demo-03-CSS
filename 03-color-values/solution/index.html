03 · Color Values

Anywhere CSS takes a colour (color, background, border-color…) you can write it in several formats. They all describe the same thing: how much red, green and blue light to mix, plus an optional alpha (transparency).

A. Named colours

About 140 colours have names. Easy to read, but you can't fine-tune them.

tomato
rebeccapurple
gold + darkgoldenrod border

B. Hexadecimal #RRGGBB

Two hex digits (00–ff, which is 0–255) for each of red, green and blue. The most common format in real projects.

#2f5d8c
#f90 = #ff9900
#000 / #fff

C. rgb()

The same three channels written as decimal numbers from 0 to 255. Mixing light, not paint.

rgb(255, 0, 0)
rgb(0 255 0)
rgb(255 255 0)
rgb(47 93 140)

D. hsl(): hue, saturation, lightness

Hue is an angle on the colour wheel (0–360). Saturation is how colourful (0% = grey). Lightness runs from 0% (black) to 100% (white). Great for making lighter and darker versions of one colour.

Hue: change only the first number (done for you)

Lightness: same hue, three shades

hsl(210 60% 25%)
hsl(210 60% 50%)
hsl(210 60% 85%)

Saturation: same hue and lightness

60% saturated
hsl(210 10% 50%)

E. Alpha: transparency

Alpha goes from 0 (invisible) to 1 (solid). The stripes behind the boxes show how see-through each one is.

solid #2f5d8c
#2f5d8c80
rgb(47 93 140 / 0.5)
hsl(210 50% 37% / 0.5)

opacity vs an alpha colour

Both boxes are "50% see-through", but look at the text.

only the background
