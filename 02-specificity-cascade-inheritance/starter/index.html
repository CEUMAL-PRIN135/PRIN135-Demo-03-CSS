02 · Specificity, Cascade & Inheritance

When several rules try to style the same element, the browser needs a way to pick a winner. Three ideas decide it: inheritance, the cascade, and specificity.

A. Inheritance

Some properties (mostly text ones like color and font-style) pass down from parent to children. Box properties like border and padding do not.

.family (the parent)

A child paragraph. Did it inherit the colour? The italics? The border?

A child with a link inside. Links have their own colour from the browser.

.child-box: a child that borrows its parent's border with inherit

B. The cascade: order and !important

When two rules have the same specificity, the one that comes later in the CSS wins.

.order-box: styled twice with the same selector. Blue rule first, green rule last.

!important jumps the queue. It even beats inline styles, so use it only as a last resort.

#stubborn.important-box: inline style says red, ID rule says blue, class rule says orange !important

C. Specificity

Different selectors, same element. The more specific selector wins, no matter where it is in the file.
