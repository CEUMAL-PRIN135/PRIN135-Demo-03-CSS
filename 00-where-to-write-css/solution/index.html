Written in a style attribute, directly on one element.

I'm styled with inline CSS. Only I get these styles.

2. Internal CSS

Written inside a <style> tag in the <head>. Works for every matching element on this page only.

I'm styled with internal CSS.

Me too: same class, same styles, written once.

3. External CSS

Written in a separate styles.css file and linked with <link>. Works on every page that links it.
