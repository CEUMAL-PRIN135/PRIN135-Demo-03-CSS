08 · Margin

Margin is the empty space outside an element's border. It pushes other elements away. It is always transparent.

A. Margin shorthand

Each orange box sits inside a grey container. The grey gap around the orange box is its margin.

margin: 10px 40px
margin: 0 0 30px 60px

A block with a fixed width and margin: 0 auto is centered horizontally.
